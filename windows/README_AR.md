# ابوناصر TV لويندوز — 1.2.0

التطبيق الأصلي لويندوز10 و11 ‏64بت يفتح واجهة ابوناصر TV على:

https://www.abbeedo.com/app

توجد نسختان: مثبت وملف EXE محمول واحد. المصدر لا يستخدم مضيف ChatGPT للتطبيق أو للتنزيلات.

## البناء

    npm ci
    npm test
    npm run build

المخرجات في dist:

- abbeedo-TV-Setup.exe
- abbeedo-TV-Portable.exe

نسخة البناء مثبتة على Electron45.2.3 وelectron-builder26.18.0. في GitHub Actions استخدم عامل windows-latest، ومجلد العمل windows. لا يتطلب البناء توكن نشر؛ تنشر خطوة GitHub Releases منفصلة ملفات الإصدار بعد اكتمالها.

## اللغة وشكل المثبت

يحدد المثبت اللغة قبل أول صفحة مرئية، ولا يعرض نافذة اختيار إنجليزية أولًا. الافتراضي العربية أو لغة المثبت المحفوظة. معاملات التشغيل المقبولة هي /LANG=1033 للإنجليزية و/LANG=1025 للعربية، أو /ABBEEDOLANG=en و/ABBEEDOLANG=ar. محدث التطبيق يمرر اللغة المختارة تلقائيًا.

المثبت يستخدم الشعار والصور المرفقة، مع خلفية فحمية ونص فاتح وألوان حمراء، وتطبيق السمة على صفحات الترحيب والمسار والتقدم والنهاية وعناصرها. النصوص والأزرار تتبع اللغة المختارة. تنصيب البرنامج للمستخدم الحالي ولا يطلب صلاحيات مسؤول. نوافذ Windows الخارجية، مثل حماية النظام من ناشر غير معروف، تتحكم بلغتها إعدادات Windows.

## التحديث داخل التطبيق

بعد تثبيت هذه النسخة مرة واحدة، افتح الإعدادات ثم تحديث التطبيق. يقرأ المحدث بيانات الإصدار من /api/releases على نفس الدومين. إذا وُجد تحديث أحدث، يتيح تنزيله داخل التطبيق، وعرض التقدم وإلغاء التنزيل. بعد اكتماله يتحقق من الحجم وSHA256 وبداية الملف التنفيذي، ثم يتحقق من البصمة مجددًا قبل تشغيل المثبت عند ضغط زر التثبيت. لا يفتح موقعًا لتنزيل التحديث يدويًا.

لا يقبل المحدث رابطًا أو اسم ملف من صفحة الويب. مصدر Setup محصور في مستودع abbeedo7/abbeedo-site على GitHub، وإعادة توجيه CDN محصورة بمضيفي تنزيل GitHub المعتمدين. لا يثبت ملفًا غير مكتمل أو معدلًا، ولا يشغّل أوامر عشوائية. انتظار نشر أول إصدار في المستودع يظهر كعدم توفر بيانات الإصدار، ولا يظهر كنجاح زائف.

## التنبيهات

بعد السماح بالتنبيهات من إعدادات التطبيق، يفحص المكون الأصلي الإصدارات والإعلانات كل دقيقة أثناء تشغيل التطبيق، بما في ذلك عند تصغير النافذة. يحتفظ بمعرفات التنبيهات لمنع تكرارها. عند الضغط على تنبيه التحديث يفتح واجهة التحديث داخل التطبيق. تنبيهات النظام تتأثر بإعدادات إشعارات Windows وعدم الإزعاج. يغلق البرنامج بالكامل عند إغلاق نافذته؛ لا توجد خدمة مخفية تعمل بعد الإغلاق.

## حفظ البيانات والانتقال إلى الدومين

يحافظ البرنامج على appId نفسه ومجلد AppData السابق باسم Abunasser TV، ولا يمسح ملفات الحسابات أو Cookies أو IndexedDB. يكتب فقط ملفات ثابتة للغة والإشعارات وموضع النافذة وتحديثاتها. تنتقل الواجهة من مضيفها السابق إلى www.abbeedo.com؛ بسبب عزل بيانات المتصفح حسب الدومين، قد يحتاج العميل لتسجيل الدخول من جديد على الدومين الجديد. تبقى ملفات الدومين القديم محفوظة ولا تُنسخ بيانات الاشتراكات عبر أصلين بطريقة غير آمنة.

## حدود التحقق

فُحصت صلاحيات الجسر وتفضيلات المستخدم ومراقبة التنبيهات والمحدث وتحقق البصمة والإلغاء وموضع النافذة. تقارير التحقق من ASAR وملفات PE والأرشيفات موجودة في validation بعد البناء. الملفات غير موقعة بشهادة Authenticode؛ لا تدّعي هذه الحزمة أنها تحمل شهادة ناشر موثوق. لم تُختبر على جهاز Windows فعلي في هذه البيئة.

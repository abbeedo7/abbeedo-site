# تحديث أندرويد من داخل التطبيق

الإصدار **3.9.4 / البناء 29** يضيف تنزيل التحديث داخل التطبيق. تحتاج النسخ الأقدم مثل 3.9.3 إلى تثبيت 3.9.4 أولًا؛ بعدها تستخدم التحديثات اللاحقة الآلية الجديدة.

1. افتح الإعدادات ثم «تحديث التطبيق».
2. عند توفر إصدار أحدث اختر «تنزيل وتثبيت». يظهر التقدم مع زر إلغاء، دون فتح الموقع أو المتصفح.
3. يتحقق التطبيق من SHA256 واسم الحزمة ورقم الإصدار وتوقيع النسخة الأصلية. يقتصر التنزيل على دومينك ومستودعك ونطاقات ملفات GitHub الرسمية.
4. قد يطلب أندرويد أول مرة السماح للتطبيق بتثبيت تحديثاته. يفتح إعداد النظام فقط، ثم ترجع للتطبيق وتضغط «تثبيت».
5. يؤكد المستخدم التثبيت في مثبت أندرويد. لا يتجاوز التطبيق إذن النظام أو تأكيده.

يمنح FileProvider قراءة ملف APK من مجلد تحديثات خاص فقط؛ لا يعرض ملفات الاشتراك. عند إلغاء التنزيل أو فشل التحقق لا يبدأ التثبيت.

نجح البناء و9 اختبارات مركزة وlintRelease بلا أخطاء، مع 36 ملاحظة تحذيرية. شهادة التوقيع مطابقة للإصدار السابق. لم يجر تثبيت فعلي على جهاز أندرويد أو نشر إلى GitHub من هذه الجلسة. التشغيل يحتاج نشر تغذية /updates.json والإصدار على GitHub.

مصدر أندرويد الكامل منفصل عن مصدر الموقع، وحزمته لا تحتوي مفتاح التوقيع الخاص. إعادة بناء إصدار يحدّث النسخة الحالية تحتاج مفتاح المالك الأصلي خارج المستودع العام.

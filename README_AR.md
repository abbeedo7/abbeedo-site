# ابوناصر TV — abbeedo.com

الموقع والتطبيق في **مشروع Vercel واحد**: الرئيسية للموقع، و/apps للتحميل والباركود، و/app للتطبيق. استُبدل محتوى البرامج السابق بروابط وصور ابوناصر TV. الخط هو ثمانية المرفق مع التطبيق، والخلفية طبقة واحدة مطابقة لحركته والقلتش.

## الرفع

1. فك ضغط الحزمة. يجب أن يكون package.json وvercel.json في جذر مستودع GitHub.
2. اربط المستودع بمشروع Vercel الذي يتصل حاليًا بدومينك، من **Settings → Git → Connect Git Repository**.
3. اختر **Other** وNode.js **22**. أمر التثبيت **npm ci** والبناء **npm run build**. إعدادات المخرجات موجودة في vercel.json.
4. احتفظ بالدومين الرئيسي الحالي كما هو. وقت الفحص كان abbeedo.com يحوّل إلى www.abbeedo.com؛ إبقاء ذلك يحافظ على أصل بيانات التطبيقات المثبتة.
5. لتشغيل خدمات الاشتراك والربط والمشاهدة، اربط **Private Vercel Blob** بالمشروع من **Storage**، ثم أعد النشر. إذا يوجد مخزن متصل بالفعل فاحتفظ به وبمتغيراته.

وقت الفحص أعاد مسار /api/health على الدومين الحالي **503 HOSTING_CONFIG**. هذا إعداد داخل حساب الاستضافة. بعد ربط المخزن وRedeploy، تحقق من ظهور **storage: true** و**mediaConfigured: true**.

شرح رفع الملفات من الآيفون: [دليل GitHub وVercel](docs/IPHONE_DEPLOY_AR.md).

## التحديث التلقائي

- **ملفات الموقع والتطبيق:** كل Push إلى فرع الإنتاج المرتبط في GitHub يشغّل بناء Vercel وينشر على نفس الدومين. لا يلزم رفع ZIP كل مرة بعد ربط Git.
- **إصدارات أندرويد وويندوز:** الروابط ثابتة على دومينك، والخادم يجلب الإصدار الرسمي المتاح عند الضغط على التنزيل. إعلان إصدار جديد في تغذية البرنامج يصل دون إعادة بناء الموقع.
- **الصفحة المفتوحة:** يتحقق الموقع من رقم المحتوى كل دقيقة أثناء ظهوره؛ يطبق التحديث عند الخمول، أو يظهر زر تحديث إذا كنت داخل الإعدادات. تبقى التفضيلات محفوظة.

التحديث يبدأ بعد نشر المصدر أو إعلان الإصدار في تغذيته الرسمية. تعديل ملف محلي خارج المستودع لا يغيّر الموقع تلقائيًا. هذه الحزمة لا تتضمن اتصالًا بحساب GitHub أو Vercel الخاص بك، ولم تُنشر على الدومين الحي من هذه الجلسة.

## الملفات

- src/: صفحات الموقع والقالب والأيقونات.
- public/assets/: الشعار والخط والخلفية والأنماط والباركودات وإعدادات الموقع.
- application/: واجهة التطبيق وخدماته، مع مسار التطبيق وتثبيت الشاشة الرئيسية.
- api/: خدمتا الإصدار والتنزيل المتجدد، ولا تحتاجان بيانات اشتراك أو مفاتيح خاصة.
- scripts/build.mjs: يجمع الموقع والتطبيق وخدماتهما في .vercel/output.
- site-config.json: الاسم والدومين ورقم الجوال والسعر السنوي الحالي 50 ريالًا.
- validation/: نتائج الفحص وحدوده.

## البناء محليًا

    npm ci
    npm run build
    npm test
    npm run dev

المعاينة المحلية على http://127.0.0.1:9020 لا تستخدم حسابات العملاء. خدمة الاشتراكات الكاملة تحتاج بيئة Vercel ومخزنها الخاص. لا يُرفع node_modules ولا .vercel ولا ملف ZIP داخل المستودع.

الآيفون يستخدم نسخة الشاشة الرئيسية PWA. ملفات Windows موجودة عبر روابط التنزيل، وليست مضمّنة داخل مصدر الموقع. قدرات الفيديو والترميزات والإشعارات مرتبطة بدعم النظام والمصدر.

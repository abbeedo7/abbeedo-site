# ابوناصر — abbeedo

المستودع العام لموقع **ابوناصر / abbeedo 2.1.5** وتطبيق **ابوناصر TV / abbeedo TV 1.2.4**.

- الموقع الحي: [www.abbeedo.com](https://www.abbeedo.com/)
- التطبيق: [www.abbeedo.com/app](https://www.abbeedo.com/app)
- التطبيقات والتنزيلات: [www.abbeedo.com/apps](https://www.abbeedo.com/apps)

في **20 نوفمبر 2026** نُشر الموقع والتطبيق على مشروع Vercel الحالي `abbeedo-tv-1.1`، بالمراجعة `web-c4d68d97eb2c7944`. مخزن Private Blob متصل، وفحص `/api/health` ناجح بحالة **200** و`storage: true` و`mediaConfigured: true`.

يحتوي المصدر على Windows **1.2.1** وAPK أندرويد **3.9.4** ومدخلات مهمة **Publish application downloads**. اكتمال ملفات التنزيل العامة يُتحقق منه في [Actions](https://github.com/abbeedo7/abbeedo-site/actions) و[Releases](https://github.com/abbeedo7/abbeedo-site/releases) بعد نجاح المهمة؛ نشر الموقع مستقل عن نشر الملفات الأصلية.

يحتفظ المستودع بإعداد النشر عبر Vercel: دفع التحديثات إلى فرع الإنتاج المرتبط `main` يشغّل بناء الموقع. النشر المباشر على مشروع Vercel الحالي معتمد من المالك بعد التعديلات المطلوبة عند توفر الوصول.

راجع [الدليل العربي الكامل](README_AR.md) و[دليل النشر والتحديث](docs/DEPLOY_2_1_AR.md) للتشغيل المحلي والتحقق وحماية البيانات.
